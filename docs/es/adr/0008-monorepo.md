# ADR: Monorepo

[English](../../en/adr/0008-monorepo.md) | [Español](0008-monorepo.md)

Estado: **Aceptado**

## Contexto

Los componentes nativos, Python y de documentación comparten un ciclo de vida.

## Decisión

Mantener todos los componentes de ORVIX en un repositorio.

## Consecuencias

Los issues, releases y el CI permanecen centralizados.
