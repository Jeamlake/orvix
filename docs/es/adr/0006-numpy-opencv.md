# ADR: NumPy y OpenCV

[English](../../en/adr/0006-numpy-opencv.md) | [Español](0006-numpy-opencv.md)

Estado: **Aceptado**

## Contexto

El caso académico propone Python, NumPy y OpenCV.

## Decisión

Utilizar NumPy y OpenCV para el motor inicial de visión de alto nivel.

## Consecuencias

Python 3.11 es la base recomendada en los sistemas actuales compatibles.
Python 3.8 permanece disponible para el objetivo heredado Windows 7.
