# ADR: Telemetría SQLite

[English](../../en/adr/0007-sqlite-telemetry.md) | [Español](0007-sqlite-telemetry.md)

Estado: **Aceptado**

## Contexto

ORVIX requiere métricas históricas sin infraestructura de servidor.

## Decisión

Utilizar SQLite.

## Consecuencias

La telemetría permanece local y reproducible.
