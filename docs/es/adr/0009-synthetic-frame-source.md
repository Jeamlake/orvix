# ADR: Fuente de frames sintéticos

[English](../../en/adr/0009-synthetic-frame-source.md) | [Español](0009-synthetic-frame-source.md)

Estado: **Aceptado**

## Contexto

Los runners de GitHub no incluyen la webcam de desarrollo.

## Decisión

Proporcionar una fuente de frames sintéticos.

## Consecuencias

Se habilitan pruebas de integración independientes del hardware.
