# ADR: Windows como plataforma inicial

[English](../../en/adr/0001-windows-initial-platform.md) | [Español](0001-windows-initial-platform.md)

Estado: **Reemplazado por ADR-0012**

## Contexto

El caso asignado permite usar API nativas de video de Windows o Linux.

## Decisión

ORVIX inicialmente apuntaba a Windows x64. ADR-0012 reemplaza esta decisión con
backends nativos para Windows, Linux y macOS.

## Consecuencias

Esta decisión registra el alcance original de la Entrega 1 y ya no define el
conjunto de plataformas compatibles.
