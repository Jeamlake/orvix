# ADR: Frames efímeros

[English](../../en/adr/0010-ephemeral-frames.md) | [Español](0010-ephemeral-frames.md)

Estado: **Aceptado**

## Contexto

ORVIX se enfoca en procesamiento y telemetría en tiempo real.

## Decisión

No guardar frames automáticamente.

## Consecuencias

Los datos visuales permanecen efímeros salvo solicitud explícita.
