# Contributing to ORVIX

[English](CONTRIBUTING.md) | [Español](CONTRIBUTING.es.md)

## Workflow

1. Select or create an issue.
2. Create a branch from `main`.
3. Implement a coherent change.
4. Add tests.
5. Update documentation in both languages.
6. Commit using Conventional Commits.
7. Push the branch.
8. Open a Pull Request.
9. Verify CI.
10. Merge.

## Branches

- feature/*
- fix/*
- docs/*
- test/*

Example: `feature/media-foundation-device-enumeration`

## Definition of Done

A feature is complete when implementation, tests, controlled errors, logging,
bilingual documentation and CI are complete.
