# Contribuir a ORVIX

[English](CONTRIBUTING.md) | [Español](CONTRIBUTING.es.md)

## Flujo de trabajo

1. Seleccionar o crear un issue.
2. Crear una rama desde `main`.
3. Implementar un cambio coherente.
4. Agregar pruebas.
5. Actualizar la documentación en ambos idiomas.
6. Crear el commit con Conventional Commits.
7. Publicar la rama.
8. Abrir un Pull Request.
9. Verificar el CI.
10. Fusionar.

## Ramas

- feature/*
- fix/*
- docs/*
- test/*

Ejemplo: `feature/media-foundation-device-enumeration`

## Definición de terminado

Una funcionalidad está completa cuando su implementación, pruebas, errores
controlados, logging, documentación bilingüe y CI están completos.
